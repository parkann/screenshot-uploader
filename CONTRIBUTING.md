# Contributing to QuickSnipUploader

Thank you for your interest in contributing! Here's how you can help.

## Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR-USERNAME/screenshot-uploader.git
   ```
3. Create a new branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development Setup

### Requirements
- macOS 14.0 (Sonoma) or later
- Xcode 15.0+
- Swift 5.9+

### Building
```bash
swift build
```

### Running Tests (when available)
```bash
swift test
```

## Code Style

- Follow Swift naming conventions
- Use SwiftUI best practices
- Keep functions small and focused
- Add comments for complex logic
- Use modern Swift concurrency (async/await)

## Submitting Changes

1. Make your changes
2. Test thoroughly on macOS 14+
3. Commit with clear messages:
   ```bash
   git commit -m "Add: Brief description of what you added"
   ```
4. Push to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
5. Open a Pull Request

## Pull Request Guidelines

- Describe what your PR does
- Include screenshots for UI changes
- Ensure the app builds without warnings
- Test on macOS 14 minimum
- Keep PRs focused on a single feature/fix

## Feature Requests

Open an issue with:
- Clear description of the feature
- Why it would be useful
- Potential implementation ideas

## Bug Reports

Include:
- macOS version
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable
- Console logs if available

## Code of Conduct

Be respectful and constructive in all interactions.

## Questions?

Open an issue or start a discussion!
